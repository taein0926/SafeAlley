# SafeAlley 소개창 로고 출처

공식 공개 페이지의 로고 원본을 수집했다. 서비스의 후원·협약 관계를 뜻하지 않는다.
소개창의 정적 자산으로 사용한다. 외부 이미지 요청 없이 제공한다.
엘티메트릭 로고(ltmetric.png)는 사용자가 제공한 원본이다.

- 기상청: https://www.kma.go.kr/kma/org/intro_mi.jsp — kma.png
- 국토교통부: https://www.molit.go.kr/USR/WPGE0201/m_91/DTL.jsp — molit.png
- 인천광역시: https://www.incheon.go.kr/index — incheon.png
- 미추홀구: https://www.michuhol.go.kr/main/main.do 의 공식 헤더 CSS — michuhol-color.png
- OpenStreetMap: https://wiki.openstreetmap.org/wiki/Logos — osm.png (현재 공식 PNG 로고의 미리보기 원본)
- 경찰청: https://bgi.police.go.kr/police/index.do 의 공식 헤더 CSS — police.png
- 소방청: https://nfa.go.kr/nfa/introduce/symbolinfo/symbol — nfa.jpg (심벌 규격 설명 이미지)

기관 로고는 각 기관의 CI·상징 사용 기준을 따른다.
OSM 로고 안내에는 OSM Foundation Trademark Policy가 연결돼 있다.
출처: https://wiki.openstreetmap.org/wiki/Logos

화면에 '데이터 제공기관' 제목은 사용자 요청에 따라 표시하지 않는다.
