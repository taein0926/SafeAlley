# 건널목 회피와 육교

현재 화면의 건널목 회피는 OSM의 footway=crossing/노드·그룹 정보 기반입니다.
일반 도로는 연결을 보완하며 최단·맞춤 모두 연결된 보행 공간을 우선합니다.
대표점 반경의 예전 교차로 비용은 새 화면 검색에서 사용하지 않습니다.

- 건널목 전체 통과 비용: crossing_weight × 80 m 상당.
- 중심선 fallback 비용으로 미등록 횡단을 0개 지름길처럼 이용하지 않게 합니다.
- 같은 다른 조건 기준 추가 우회는 min(30%,300m)로 제한합니다.
- minimize와 강한 avoid는 다릅니다. 무건널목 경로가 없으면 조건을 몰래 완화하지 않습니다.
- 육교는 실제 OSM bridge/layer 연결과 제공된 참조 매칭만 사용합니다.
- 육교 우선 카드는 입력 중 독립적으로 인식하지만 독립 강제 경유 가중치는 없습니다.
- 전체 건널목 비교가 불완전하면 미지원/부분 자료로 구분합니다.
- 공식 POI는 출처 대조용이며 가까운 일반 도로에 임의 횡단선을 생성하지 않습니다.

예전 교차로 API 필드와 migration/참조 테이블은 이력 호환을 위해 남겨 둡니다.
이는 현재 UI에 교차로 회피나 전체 횡단 POI 레이어가 있다는 뜻이 아닙니다.
옛 후보 표시·현장 보류 UI·도시 일부 수집 기준 결과 수치는 현재 안내에서 제거했습니다.

정확한 비용과 strong avoid, UI mapping은 [routing.md](routing.md).
원천/갱신은 [data-pipeline.md](data-pipeline.md), 검증은 [testing.md](testing.md).
