# 첫 접속 소개창

React의 `WelcomeIntro`가 브라우저 네이티브 `dialog`로 소개창을 표시한다.
기존 지도·길찾기·DB·LLM 판정은 변경하지 않는다. 회사·기관 로고는
`frontend/public/branding`의 원본 이미지를 사용하며 출처는 `SOURCES.md`에 기록한다.

- 같은 브라우저 세션에서 한 번 표시한다. 닫을 때 `sessionStorage`에 기록한다.
- 닫기 버튼, Escape 또는 소개창 바깥의 어두운 영역을 클릭해 닫는다.
- 자동으로 닫히지 않으며 길찾기 시작하기 버튼도 표시하지 않는다.
- 닫은 뒤 다시 여는 서비스 소개 버튼은 없다.
- 출처 기관 로고는 한 줄로 표시하고 작은 화면에서는 가로로 스크롤할 수 있다.
- 회사 로고와 서비스명 사이에 여백을 두고, 배경 상자 대신 얇은 열린 인용선과 파란 따옴표로 `골목에 안전을 더하다` 슬로건을 강조한다.
- 기능 카드를 나열하지 않고 `입력 → AI 분석·경로 제안`의 2줄 설명으로 자연어 기반 안전 보행 경로 서비스임을 전달한다.
- 개인정보 보호 설정으로 세션 저장이 차단돼도 닫기는 동작한다.
  이 경우 새로고침하면 다시 나타날 수 있다.
- 작은 화면에서는 소개창 내부를 스크롤할 수 있다.

테스트: `cd frontend`에서 `npm test`, `npm run build`.
별도의 API 호출·외부 모델 전송이나 DB 변경은 없다.
