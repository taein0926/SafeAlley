# 검색 진행과 후보 카드

## 현재 화면

검색창은 지도 왼쪽의 높이 95vh 플로팅 패널로 세로 중앙에 위치합니다.
상단 입력/버튼은 유지하고 아래 실제 경로 처리 내용만 독립 스크롤합니다.
결과 카드와 건물 상세는 검색창 오른쪽의 같은 시작 위치를 사용합니다.

- 진행 중 생각하는 로봇, 완료 시 파란 체크. reduced-motion에서 애니메이션을 끕니다.
  로봇은 푸른 원 안에 위치합니다.
- 최단/맞춤 후보. 시간·거리 바로 아래 계단·육교·횡단보도 요약을 배치합니다.
- segment 순서/geometry가 같으면 하나만 표시합니다.
- 후보 탭·자세히 보기·계산값 비교표·폐기한 하단 안내 문구는 없습니다.
- 선택 카드 투명도 42%, 다른 카드 50%, blur 1px. 내부 배지 투명도 30%.
  텍스트까지 흐리게 하는 opacity는 쓰지 않습니다.
- 카드 선택은 경로/marker와 연동합니다. 2D/3D는 별도 버튼이며 선택 상태를 유지합니다.
- 검색창을 접어도 후보 카드와 접기 버튼 간격은 유지합니다.
- 입력 수정/예시 선택은 결과창을 감춥니다. 문장 입력 모드의 요구사항 카드는 검색 전·중·후에도 유지하고 직접 설정에서는 숨깁니다.
  이전 지도 경로는 새 성공 결과 전까지 유지될 수 있습니다.

## 스트림·미리보기 구분

POST /api/agent/query/stream은 interpreted, 장소 확인, route_progress,
최종 result/error를 NDJSON으로 전달합니다. 실제 작업 단계이며 비공개 모델 추론이 아닙니다.
작업 ID별 메시지를 갱신하며 실패를 완료처럼 처리하지 않습니다.
Nginx는 proxy_buffering off. query/execute도 같은 라우팅 서비스를 사용합니다.

추천 조건 카드는 최종 API를 사용하고 입력 중 Jev 상태로 결과를 덮어쓰지 않습니다.
시설 주변 등록 위치 집계는 설명용이며 실제 밝기/안전과 다릅니다.

입력란 아래 조건 순서: 거리·가로등·CCTV·안전시설 / 계단·건널목·육교·시간대.
4×2 작은 카드에서 인식된 조건은 배경 없는 빨간 체크로 표시합니다.
띄어쓰기 경계와 마지막 단어 idle을 분석하고 예시 자동 타이핑도 같은 흐름을 사용합니다.
예시는 공백에서도 멈추지 않고 글자마다 25ms 간격으로 입력합니다.
제목은 요구사항 분석/분석 중/완료/불가이며 실제 입력 분석 중에만 세 점이 움직입니다.
빈 입력은 미선택 카드만 표시하고 Jev를 호출하지 않습니다. 검색 시작 시 미리보기를 멈추고
마지막 판단을 보존하며, 최종 경로 카드의 판정과 섞지 않습니다.
육교는 독립 응답을 유지하고 건널목 회피에서 자동 선택하지 않습니다.
입력 중 인식은 실제 경로 적용 확정이 아닙니다.
