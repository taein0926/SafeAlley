# Qwen3.6 적용 및 검색 품질 보정 — 2026-10-08

## 실행 구성

기존 개선 MR !5는 main `99242aa`에 반영됐다. 이후 최신 원격 main `99242aa`를 받아
`codex/request-guards-main-20261008`에서 요청 카드·개인화·미완성 조건의 후속 보정을 적용한다.
담당자의 일반 도로 대체 경로 추천 정책과 기존 UI는 유지하며, 이 후속 수정은 별도 브랜치 MR로 전달한다.
VM에는 배포하지 않았다. PC의 Docker 프론트엔드·FastAPI·담당자 PostgreSQL/PostGIS는 유지하고,
자연어 해석만 GPU 서버의 Ollama `qwen3.6:35b`에 요청한다. Jev는 기존 TypeSafe 외부 API다.
키와 실제 환경변수 파일은 Git에 포함하지 않는다.

브라우저 → FastAPI → Ollama(JSON Schema와 질문 전달) → Qwen JSON 응답 →
Pydantic 형식 검사 및 의미 검증 → 장소 자료 조회 → rank_routes → 경로·지표·설명 응답 → 브라우저.
입력 중 Jev 요청 판단과 검색 후 경로에 실제 반영된 조건은 서로 다른 단계다.
Jev를 경로 계산기나 Qwen의 무조건적인 정답으로 사용하지 않는다.

## 변경 이유와 작동 방식

1. **한글 시각 검증**: 모델은 ‘밤 열한 시’를 23시로 추출했지만 기존 Python 검증이 숫자 시각만
   인정해 삭제했다. 시간 검사에 한정해 한~열두 시를 숫자로 정규화한다. 모델에 보낼 원문이나
   장소명은 바꾸지 않는다. 출발·도착 역할 검사, 시간 철회·수정 처리는 기존 검증과 함께 사용한다.
   ‘밤에’처럼 시각이 없는 말은 특정 시각으로 만들지 않는다.
2. **접근성 방향 설명**: 경찰서 접근성은 접근하기 좋은 정도이며 거리 값이 아니다.
   프롬프트에 가까움=maximize를 명시했다. 이번 80건의 해당 사례는 통과했다.
   현재 경찰서 전용 접근성 지표가 미지원이면 다른 지표로 몰래 바꾸지 않는다.
3. **요청과 기본 정책 분리**: ‘안내해 줘’에서 모델이 distance_m을 추가하는 실패를 발견했다.
   거리·길이·속도·우회 표현이 전혀 없으면 이 추정 조건만 제거한다.
   기본 경로 정책은 기존 rank_routes가 결정한다. 이 보정은 제한된 규칙이며 모델 자체의 학습이 아니다.
4. **건널목 실행과 비교 분리**: 경로 생성에서 실제 사용한 양의 건널목 비용과 등록 개수를 확인한다.
   부분 자료라도 줄이기(minimize) 비용을 사용했다면 카드에 적용을 표시한다.
   application_scope=route_generation, data_quality=partial로 표시 의미를 전달한다.
   전체 개수 지표의 null과 자료 부족 사유는 유지한다. ‘건널목 없이’(avoid)를 충족했다고 주장하지 않는다.
   카드 툴팁, 과정 설명, 추천 근거도 이 구분을 사용한다. 경로 알고리즘과 비용 값은 변경하지 않았다.
5. **시간대 카드**: 자연어 검색은 지정한 출발 시각이 있을 때만 카드에 표시한다.
   시각 미지정 시 현재 시간 정책은 계산에 사용할 수 있지만 요청 카드에는 표시하지 않는다.
   직접 Tool의 기존 개인화 모드에서는 현재 시간 정책 사용을 툴팁으로 설명한다.
6. **연결 실패**: GPU 모델 접속·응답 실패 시 SSH 터널과 서버 상태 확인 안내를 반환한다.
   다른 모델로 조용히 전환하지 않는다. 응답 형식 실패는 기존 최대 1회 재요청을 유지한다.
7. **UI**: 마지막 입력 후 2초 동안 수정이 없고 현재 문장의 Jev 응답이 반영되면
   ‘요구사항 분석 완료’로 표시한다. 빠른 응답이나 1초 입력 휴지에는 ‘분석 중’을 유지하고,
   다시 입력하면 즉시 완료를 해제한다. 이전 문장의 응답이나 오류로 완료 처리하지 않는다.
   이 타이머는 표시만 조절하며 Jev 호출 스케줄을 바꾸지 않는다.
   작은 화면에서는 결과를 하단 패널로 배치하고 지도 시점 버튼을
   날씨 아래로 내려 겹침을 줄인다. 데스크톱 담당자 레이아웃과 로봇·파란 체크는 유지한다.

## 평가와 해석상의 주의

공개 회귀 70건과 AI 작성 탐색 문장 10건으로 Qwen3.6 80건을 실측했다.
독립된 사람 검수 holdout은 아니다. JSON/Pydantic 기본 정규화 후, 의미 보정 전에는 72/80(90%),
당시 의미 보정 후 79/80(98.75%)였다. 모델 호출은 최초 80회+재시도 1회=81회다.
중앙 응답시간 0.964초, p95 1.541초. 경로 계산·전체 화면 완료 시간이 아니다.

남은 ‘일반 안내에 최단거리 조건 추가’를 보정한 뒤 저장된 실제 응답을 외부 접속 없이 재생했다.
최종 재생 80/80은 같은 자료의 보정 회귀 결과이며, 새 질문 정확도 100%를 뜻하지 않는다.
이전 Qwen3:30b는 보정 후 78/80, 중앙값 0.510초였다. 프롬프트와 보정 코드가 달라졌으므로
동일 조건의 모델 우열 비교로 단정하지 않는다. Qwen3.6이 이번 측정에서 더 빠르지는 않았다.

Jev는 승인된 공개 문장 5건을 추가 실호출했고 5/5 요청 조건을 인식했다.
저장된 Qwen3.6 결과와 비교한 5건의 요청 조건은 일치했다. 이는 모든 문장의 일치 보장이 아니다.
해당 결과로 실제 DB 장소 조회와 Tool 실행도 구성 재생했다. 별도의 신규 LLM 호출은 하지 않았다.

## SSH 연결 유지와 복구

PC PowerShell의 SSH 터널 창이 열려 있어야 Docker가 host.docker.internal:11435로 접근할 수 있다.
절전·재부팅·창 종료 후에는 터널을 다시 열고 비밀번호를 터미널에 직접 입력한다.
비밀번호·개인키를 코드나 문서에 기록하지 않는다. 서버 주소도 사내 공유 정책을 따른다.
GPU 서비스와 터널이 정상인데 실패하면 모델 적재 상태, 서버 사용량, 응답 시간제한을 확인한다.
비밀번호 기반 자동 재연결 서비스는 구성하지 않았다.

## 남아 있는 한계

- Jev·Qwen의 모든 새로운 문장 판단이 같다고 보장하지 않는다. 입력 중 판단은 잠정 요청 인식이다.
- 부분 도로 자료로 실제 보행 가능성·전체 건널목 수·실제 조도·안전을 보장하지 않는다.
- 실제 음성 인식·GPS 권한·현장 보행은 이번 검증 범위가 아니다.
- GPU의 262144 기본 컨텍스트는 변경하지 않았다. 서버 공통 설정을 임의로 변경하지 않는다.
- 슬라이드는 제작하지 않는다. 코드·테스트·이 문서는 별도 브랜치 MR로 전달한다.

## 후속 보정: 요청 카드와 과거 선호 분리

자연어 query/stream은 RouteOptimizationArguments.preference_mode를 explicit_only로 지정한다.
조건이 없는 질문은 과거 선호를 읽지 않고 기본 거리 기준으로 계산한다. 기존 선택 기록은 삭제하지 않는다.
계산용 기본 조건과 표시용 명시 조건은 별도로 유지한다. 시간만 말하면 시간대 카드만 켜지고,
최단거리·CCTV·계단·건널목을 명시하면 실제 반영 가능한 조건만 켜진다. 낮 시간 가로등 제외는 유지한다.
시간을 말하지 않은 자연어 질문은 현재 시간 정책을 계산에 사용하지만 시간대 요청 카드에는 표시하지 않는다.
직접 Tool API의 personalized 모드는 기존 동작을 유지한다. 자연어 검색만 이번 요청 기준으로 바뀐다.
과거 선호가 존재하는 사용자를 모의로 넣어 자연어 검색이 이를 읽지 않는 회귀 테스트를 추가했다.

## 후속 보정: 미완성 조건을 추측하지 않기

incomplete_conditions.py는 문장 끝에서 명사·조사만 남은 조건 목록을 검출하는 제한된 보호 코드다.
예를 들어 'CCTV가 많고 건널목을'에서는 CCTV 요청은 유지하고 건널목의 추정 방향만 제거한다.
Qwen 반환 조건은 이 검증을 통과한 항목만 Tool로 보내며, Jev가 같은 미완성 항목을 적용으로
판단해도 입력 카드에서는 pending/분석 중으로 보정한다. 추가 모델 호출을 만드는 검증이 아니다.
'계단과 건널목을 적게' 같은 완성된 복합조건은 유지한다. 앞에서 완성한 같은 조건을 단순히
다시 언급한 미완성 문장이 앞선 요청을 지우지 않도록 보호한다.
이 코드는 모든 한국어 문법을 판정하는 파서가 아니며, 문장별 예외를 기억하는 학습도 아니다.

후속 브랜치 검증: 백엔드 단위 테스트 327개, 프론트엔드 단위 테스트 194개 통과.
실제 GPU Qwen과 담당자 DB에서 시간만 있는 질문, 미완성 건널목 질문, 완성된 건널목
줄이기 질문 3건을 확인했다. Jev 보정은 모의 응답으로 테스트했으며 추가 유료 호출은 하지 않았다.

## 담당자 적용 시 설정

MR에는 실제 .env, API 키, SSH 비밀번호, DB 백업, 지도 타일이 포함되지 않는다.
모델 변경은 사용 환경별 설정이며 기존 기본 모델값을 강제로 바꾸지 않는다.
GPU 서버 연결이 허용된 환경에서 OLLAMA_BASE_URL을 접근 가능한 Ollama 주소로,
OLLAMA_MODEL을 qwen3.6:35b로 설정한 뒤 backend 컨테이너를 재생성한다.
기존 담당자 DB·Jev·기상청 설정은 그대로 유지한다. GPU 내부 주소는 문서나 Git에 기록하지 않는다.
